# الواسطي | alWasiti

استوديو التصميم العربي الحديث — مجاني، مع إعلانات غير متطفلة خارج المحرر.

**حالة الإنتاج:** V1.4 Production Hardening لم تجتز بوابة قبول ≥9/10 في كل محور حتى الآن. لا تُدمج أي نسخة تجريبية إلى `main` قبل اكتمال اختبارات التوافق، والأمان، والدقة، والتراخيص، والنشر.

النسخة التجريبية على الفرع `hardening/v1.4`، ويتولى GitHub Actions اختبارات القبول قبل أي ترقية.

الموقع الأساسي: https://alwasiti.vercel.app/
