# الواسطي — 12 قالب انطلاق عربية أصلية (V1.4 Content Gate)

Content scope: twelve authored **starter presets**, not stock images, logos from historical manuscripts or preexisting branded designs. They are implemented using the existing original geometric/text tools and local HTML/CSS thumbnails. No additional font binaries, imagery, templates purchased from marketplaces or external icons are included.

Editable properties per template: project/brand name, tagline, CTA, four brand colors, heading/body fonts, typography weight, shape/monogram, vector export font, logo layout/placement, component radius/button style/shadow, light/dark mode. The current existing editor exports SVG (text and outlines), transparent PNG, design tokens JSON, CSS variables and project backup JSON.
