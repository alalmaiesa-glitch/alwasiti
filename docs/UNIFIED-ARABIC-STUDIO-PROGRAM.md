# الواسطي الشامل — برنامج بناء منصة تصميم عربية متطورة

**القرار المعتمد:** بناء منصة أصلية شاملة تتنافس على فائدة أدوات أندلسي وتطمح لتجاوزها في العمق العربي والجودة المتجهية. لا نسخ للشيفرة أو أصول التصميم أو القوالب المملوكة لأندلسي. هذا فرع **اختباري منعزل**؛ لا تعديل على الإنتاج.

## المقارنة المرجعية
يوثق موقع أندلسي 38 ميزة، تشمل محرر صور وفيديو، قوالب، تحريك، تصميم متعدد الصفحات، نص منحني، مكتبة خطوط، AI ومخرجات متنوعة. حجم المحتوى الفعلي هائل؛ لا يمكن ادعاء بلوغ التكافؤ بمجرد رسم واجهة مشابهة.

## ما نختبره فعليًا الآن
أُنشئ \`app/creative-studio/\` كمنتج تجريبي جانبي **لا يحل محل المحرر الحالي**:
- مستند v1 مستقل يدعم حتى 20 صفحة و200 طبقة للصفحة؛ مقاسات مربع/ستوري/أفقي/A4.
- أربع طبقات: نصوص عربية و rectangles و ellipses وصور PNG/JPEG/WebP من المستخدم (حتى 2 MB).
- تحرير مباشر وdrag بالماوس/اللمس، نسخ/ترتيب/حذف طبقات، Undo/Redo حتى 60 خطوة.
- أربعة تكوينات أصلية مختلفة: ملصق ثقافي، دعوة، إعلان تجاري، اقتباس عربي.
- تصدير صفحة SVG وPNG، وملف المشروع JSON متعدد الصفحات؛ إعادة استيراد JSON؛ حفظ محلي.
- يعمل بلا API أو خدمة مدفوعة ولا يرسل التصميم إلى خادم. لا صور تاريخية أو مخطوطات من الواسطي.
- الصور المحلية محفوظة بصيغة Data URL في المشروع. حد حجم البيانات/الحفظ يعتمد على المتصفح.

## حدود V0.1 معلنة صراحة
1. النص في SVG هو \`<text>\` وليس Glyph Outlines؛ قد تختلف الخطوط على الأجهزة. لذلك **غير معتمد بعد** لتسليم شعار تجاري متجهي.
2. تصدير PNG صفحة واحدة؛ لا PDF متعدد الصفحات ولا فيديو ولا إزالة خلفية ولا أدوات AI في هذا النموذج.
3. المزامنة السحابية ليست مفعلة؛ لا تتطلب Supabase.
4. واجهة التحرير الأصيلة تختلف عن أندلسي. لا يجوز إدخال أصول خارجية إلا بتراخيص مناسبة للاستخدام التجاري مع الإعلانات.
5. لا يُسمح بدمج هذا الفرع مع \`main\` أو \`hardening/v1.4\` أو \`content/v1.4-templates\` إلى أن يغلق معيار V1.4 والجودة ≥9/10 بمحاور مستقلة.

## خطة المحرك الهندسي المفتوح المصدر
- الأساس الحالي SVG Model مستقل لتجنب حبس البيانات داخل مكتبة محددة.
- **Konva (MIT)** مرشح للطبقات والسحب والتحويلات، و**Fabric.js (MIT)** مرشح للتعامل مع SVG/Canvas؛ نختار بعد اختبار عربي بصري وأداء، ولا ندخل اعتماديات غير مدققة تلقائيًا.
- **Fontkit** المعتمد في محرر الواسطي السابق مسؤول مستقبلاً عن Arabic OpenType shaping ومسارات النص.
- **ffmpeg.wasm** مرشح تقني للفيديو مستقبلاً؛ يجب مراجعة ترخيص نواة FFmpeg وcodecs تحديدًا، لا الاكتفاء برخصة JS.
- تتطلب الوظائف السحابية المكلفة ميزانية وحدود استخدام؛ الأدوات المحلية أساس المنتج.
