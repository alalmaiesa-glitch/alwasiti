# الواسطي | alWasiti — V1.4 Production Hardening (Candidate)

نسخة تجريبية مجانية مستقلة: أنظمة ألوان وخطوط عربية وشعارات SVG/PNG، مع تحويل العربية إلى مسارات SVG بواسطة Fontkit 2.0.4.

**حالة الإصدار:** Candidate غير معتمد للإنتاج العام. فحوص المتصفح المحلية 50/50، لكن لا يزال الاختبار على النشر، وربط المستودع، وتأكيد الخطوط الخارجية مطلوبًا قبل عبور بوابة 9/10.

## التحسينات

- تصحيح المسافات في تحويل النصوص العربية الطويلة إلى مسارات، ودعم النصوص المشكّلة.
- حساب viewBox موسع للشعارات الطويلة أو المنقولة لضمان عدم اقتصاص حواف SVG؛ ضبط PNG بنفس الحدود.
- فصل لقطة إعدادات الشعار عن عمليات تحميل الخطوط غير المتزامنة، مع مهلة 12 ثانية وخطأ واضح.
- حفظ مسودة احتياطية تلقائيًا في localStorage واستعادتها عند إعادة فتح الصفحة؛ لا يوجد حفظ سحابي.
- تطبيع JSON المستورد والمباشر والتحقق من اللون والأرقام وأطوال النصوص؛ حماية من إدخال HTML.
- حركة دقيقة على لوحة SVG مع تكبير العرض، وفوكس للحوارات، وTab trap وEscape.
- إضافة ترويسات CSP وأذونات أمنية في `vercel.json`، وصفحات خصوصية وشروط تجريبية.
- سجل تراخيص مكتبات JavaScript وأصول الخطوط. **لا تتضمن الحزمة أي ملفات خطوط.**

## التشغيل المحلي

من مجلد `app/`:

```bash
python -m http.server 8080
```

افتح `http://localhost:8080/`. تحتاج زيارة المصدر الرسمي لأول تحميل للخطين Noto Kufi Arabic وAmiri عند تصدير Vector. الخطوط الأخرى قد تُحمّل من Google Fonts للمعاينة. لا تستخدم بيانات سرية في مشاريع browser-only.

## الاختبارات

في مجلد الإصدار إن توفرت Chromium + Python Playwright + خطوط اختبار مثبتة محليًا:

```bash
python tests/acceptance.py
```

يعتمد اختبار الخطوط على خطوط نظام الاختبار المرخصة، **لا تُدرج في التوزيعة**. يمكن تحديد مساراتها بواسطة متغيري `ALWASITI_TEST_FONT_AMIRI` و`ALWASITI_TEST_FONT_NOTO`.

## القيود قبل الإنتاج

- مستودع GitHub `alalmaiesa-glitch/alwasiti` غير موجود/غير متاح عند الفحص؛ لا توجد CI ولا إمكانية إثبات التراجع عن الإصدار.
- لم يُتحقق من تدفق التحميل الحقيقي من GitHub Fonts عبر نشر Vercel لهذه النسخة.
- نتائج المتصفح من Chromium؛ يلزم Firefox/WebKit وفحص قارئات الشاشة يدويًا.
- قانونية الإعلانات وتحديث سياسة الخصوصية متطلبان قبل تفعيل أي برنامج إعلاني.
- Fontkit 2.0.4 تُستخدم فقط مع قائمة خطوط موثوقة، ويُمنع رفع ملفات TTF غير موثوقة نظرًا لمخاطر ملفات خطوط مصممة بخبثًا.
- ملفات ترخيص المصادر في `LICENSES/` والنسب في `THIRD-PARTY-NOTICES.md`، مع وجوب تدقيق نهائي قبل التوزيع العام.
